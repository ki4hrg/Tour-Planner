# Design & usability audit — October 2026

Hands-on audit of the running app at desktop (1280) and phone (393/360) widths
against a seeded seven-day trip. One file per area; each has an executive summary,
findings with severity + file:line pins, and a "what works well" list.

- [initial-planning.md](initial-planning.md) — sketching a new tour, reaching contacts, open dates and last year's slot
- [detailed-planning.md](detailed-planning.md) — adjusting the itinerary, costs, workflows, constraints
- [during-tour.md](during-tour.md) — reflowing the day on a phone, confirming contacts on site
- [mobile.md](mobile.md) — per-route overflow / tap-target table and systemic causes
- [design-language.md](design-language.md) — rule coherence, consistency scorecard, proposed CLAUDE.md rule additions
